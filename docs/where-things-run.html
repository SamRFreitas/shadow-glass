Where things run

The one sentence that matters most: Windows isn't part of this story yet. Everything that has run so far happened inside a single thing — the Mac app — which calls functions that live inside a C library. That's not the same as "connecting" to it over a network; it's all one program.

The acronyms — and when they'll actually start mattering

None of these apply to anything we tested yet, because nothing left the Mac. They describe what happens starting at the exact moment the offer text tries to cross to Windows — the next piece we're building.

UDP
sends packets over the network with no built-in guarantee they arrive, or arrive in order.
DTLS
"TLS for UDP" — the same encryption behind HTTPS, adapted for unreliable packets.
SCTP
adds back ordering/reliability once encryption is in place — what a DataChannel is built on.
ICE / SDP
the "how do we find each other and agree on a connection" negotiation — the offer text from our test is SDP; its ufrag/pwd fields are ICE credentials.

What this snapshot doesn't show

On purpose: build output (.build/, build/), the vendored library's own huge internal tree, and anything gitignored. The point of a snapshot is the shape we authored, not what a toolchain generates or a dependency brings along.

Where this fits

This page was made the same day the decision to start a second, separate project — a research/learning journal about harness engineering itself — was made. This snapshot is the "before" picture: what Shadow Glass looked like the day that journal was born.
